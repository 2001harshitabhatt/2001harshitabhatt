### 🏗️ Featured Engineering Projects

#### 📈 [Real-Time Market Stock Data Pipeline](https://github.com/2001harshitabhatt/real-time-stock-data-pipeline)

> **Stack:** `Python` • `Apache Kafka` • `Spark Structured Streaming 3.5` • `PostgreSQL` • `Docker Compose` • `Spring Boot`

*   Engineered an end-to-end event-driven streaming pipeline ingesting live market tick data across 50+ equities with sub-second latency.
*   Implemented Spark-level stateful deduplication and Dead Letter Queue (DLQ) for **exactly-once processing** guarantees and fault resilience.
*   Pre-aggregated 1-minute OHLCV financial rollups into B-tree indexed relational storage, exposing data via a Spring Boot REST API.

#### 🛒 RetailPulse Cloud Data Platform

> **Stack:** `PySpark` • `AWS Glue` • `Amazon S3` • `Amazon Athena` • `AWS Step Functions` • `Terraform`

*   Designed an enterprise **Medallion Architecture (Bronze $\rightarrow$ Silver $\rightarrow$ Gold)** on AWS S3 processing batch sales and inventory data.
*   Built automated data quality checks and schema enforcement to safeguard reporting layers.
*   Optimized query latency in Amazon Athena through Snappy-compressed Parquet files and Hive-style partition pruning.
*   Entire infrastructure provisioned as code via **Terraform** and scheduled using **AWS Step Functions**.

> **Stack:** `Python` • `OpenCV` • `Dlib` • `Computer Vision`
